# OptiCut — Bars and boards on one cutting list

OptiCut keeps one named cutting list on the desk: the live lengths, the remnant step in front of you, and a short note the next run can read. Extra bars wait for their own title.

## Session Card

| Slice | What you do in OptiCut | What remains |
|-------|------------------------|--------------|
| Arrival | Open OptiCut and name today's bar and board job | A titled shop plan |
| Focus | Keep only live lengths on the OptiCut desk | A short cutting list |
| Check | Read the OptiCut remnants before a large change | A confirmed bar set |
| Handoff | Mark finished runs inside OptiCut | A note for the next list |

## How OptiCut Sits

OptiCut works from the bars and boards you already keep. It does not take the saw's place. It is a named shop plan for one cutting list: which lengths are open, which remnants are pinned, and what the next run should read.

If two people share a saw desk, each keeps an OptiCut list of their own. Extra bars wait for their own title instead of crowding the live remnant pile.

## Traffic Light

| Signal | On the OptiCut board | What you do |
|--------|----------------------|-------------|
| Green | Named list, short bar set | Continue the same run |
| Amber | Lengths from two jobs mixed | Split the set before a large change |
| Red | No title, bars without a list | Stop and name the OptiCut plan first |
| Clear | Handoff written, remnants few | Close OptiCut and leave the shop plan |

## Open Order

1. Open the last OptiCut list, not a new empty plan.
2. Read the remnant bars and the last handoff.
3. Finish one visible length step inside OptiCut.
4. Write what changed, then close with fewer loose bars than you found.
5. If the list feels crowded, drop anything that belongs to a different OptiCut job.

## After a Week

Friday on OptiCut is a shorter cutting list, not a thicker remnant pile. It is the same title, fewer loose bars, and a note that still makes sense on Monday.

Take finished runs off the live set so the next visit starts on the bars and boards that are still open. Leave OptiCut with a quieter shop plan than the one you opened.

## Sign-off

- [ ] The OptiCut list name is short enough to scan
- [ ] Only live bars and boards you own are on the desk
- [ ] A second person can read the handoff
- [ ] The last OptiCut session still opens after a restart
- [ ] Finished runs are off the live OptiCut set

## Field Note

OptiCut stays useful when the remnant bars still match the list you started. Name the plan, keep the live lengths, finish one visible cut, and write what changed. Extra bars wait for their own title.
